**HTML (HyperText Markup Language):**

HTML is the basic building block for all web pages. It is a markup language used to structure the content.

HTML uses so-called "tags" to define elements such as headings, paragraphs, images, and links. These tags provide instructions to the browser about how the content should be presented and organized.

There are many HTML elements available and for more information, I have included a link to W3Schools which has a comprehensive overview of HTML elements.

This isn't something you need to memorize, but it can be helpful to have a basic understanding of what's available.

**Semantic HTML:**

Semantic HTML is about using HTML elements that clearly describe the content they surround. By using semantic elements, we help browsers, search engines and aids such as screen readers to better understand the structure and content of a website. 

Instead of generic elements like <div> and <span>, we use more descriptive elements like <header>, <article>, <section>, and <footer>. Headings such as <h1> to <h6> also provide a hierarchy that makes it easier for search engines to understand which parts of the page are most important.

Semantic HTML also improves accessibility and SEO (search engine optimization), as it makes it easier for search engines to index the content and for users with disabilities to navigate the website using assistive devices.
